# 底部拨轮（Android 1.6.3）

应用内所有按钮、下拉菜单、模型列表和屏幕上传授权选择改为同一个底部拨轮。配置引导每一步仍只处理当前项目；上方正文和输入框可以滚动，拨轮固定在下方。键盘弹出时拨轮位于键盘上方，保留原有输入框和系统输入法。

## 操作

- 在底部区域向左滑：下一项；向右滑：上一项。每约 56 dp 经过一档，播放约 23 毫秒的本地咔哒声，并请求系统轻触觉反馈。到第一项或最后一项即停住，不循环绕回。
- 停稳后朗读“第几项、共几项、名称、是否可执行”；连续转动只排队朗读最后停下的选项。快速继续滑动会停止上一次播报。
- 单击重听当前项，双击执行。滑动和停留不会发起 API 请求、改变授权或保存选项。
- 接口、模型及授权选择会进入下一层拨轮。双击确认后返回；“取消选择，返回”或 Android 返回键不会保存浏览中的选项。设置说明菜单也提供返回项。
- 禁用项会读出暂不可用，双击不会执行。声音和触觉的实际强度受手机音量及系统设置影响。

## 手机读屏与语音

拨轮向系统提供可调整控件的序号、总数，以及上一项、下一项、执行当前项操作。TalkBack 下先聚焦拨轮，再使用双指横滑或读屏的调整操作，双击执行。普通单指左右滑在 TalkBack 下用于移动无障碍焦点；不应假设所有厂商读屏都会把它交给应用。参见 [TalkBack 手势](https://support.google.com/accessibility/android/answer/6151827?hl=zh-Hans) 和 [Android 自定义控件无障碍说明](https://developer.android.com/guide/topics/ui/accessibility/views/custom-views)。

没有系统读屏时，使用手机中文 TTS 以正常语速朗读选项。启用读屏时，通过无障碍事件播报，避免应用 TTS 同时讲话。中文语音缺失时仍保留文字及读屏接口，需要在系统安装中文 TTS；本功能不下载或调用云端人声。

配置语音仍可使用“小助手，下一步”等命令。在引导页朗读选项时，不将其当作配置命令。日常屏幕描述的唤醒处理在本应用配置界面暂停，回到其他应用恢复，避免菜单播报误触发识图。

## 密钥和系统页面

“编辑密钥”打开密码输入框；“粘贴密钥”仅在本人双击或明确说出粘贴命令时读取剪贴板。拨轮名称不包含密钥内容，不做密钥听写。屏幕上传默认不允许，需进入授权选项并明确执行允许。保存或测试仍需分别执行。

Android 权限弹窗、系统设置和输入法不是本应用的控件，仍由手机读屏操作，无法替换成这个拨轮。

可选的跨应用悬浮入口也采用底部拨轮，默认隐藏；显示后会占据其他应用底部一条区域，可随时通过拨轮或语音隐藏。它在听见世界内部自动收起，以免遮挡页面拨轮。

## 验证边界

已检查真实触摸事件、选择不执行、双击只执行一次、取消不保存、停稳朗读去抖、离开页面取消播报，以及读屏动作接口。模拟器还检查了正文滚动和键盘弹出时的固定位置。机械声资源为程序合成的短音，不含录音或外部音频授权内容。

这些检查不等于一加 Ace 2 的实际声音、触觉、TalkBack 全流程或视障用户验收；需要真机感受档位间距、音量和停顿是否合适。

1.6.1 调整为浅色细弧形拨轮，配置页显示步骤进度、简短提示及当前值卡片。视觉提示和完整语音说明分开排版，重听仍提供完整内容。

1.6.2 将模型服务入口固定命名为“模型接口配置”，上方仍显示当前服务商。双击入口后进入服务商列表，滑动浏览不会保存，双击选项才确认。

## 配置语音没有反应时

1. 先双击“开启配置语音操作”，允许麦克风。首次需等待离线模型准备，模型和录音准备完成后才响提示音。
2. 听到提示音、读屏声音结束后，15 秒内直接说“下一步”“上一步”或“选择第二项”，说完稍等。入口就绪后叫“语音说一项”，每次双击接收一条指令。
3. 未听清或没收到可用指令会提示重试，不会把识别出的原话或密钥显示、朗读出来。该功能只识别固定配置指令，不回答聊天问题。
4. 若提示麦克风被暂停，检查应用麦克风权限、手机快捷设置中的麦克风总开关，结束占用麦克风的录音或通话后再试。识别声音不上传 API。

非读屏模式也可在提示结束后用“小助手”开头说指令；短时输入以外的普通对话不会作为配置命令。连接测试、开启自动功能和上传授权仍会先复述，要求单独确认。
