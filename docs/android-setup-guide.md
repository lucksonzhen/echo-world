# Android 无视觉配置与操作（1.6.7）

配置未完成时，启动应用自动进入逐项引导。已完成用户可通过主界面的“逐项设置引导”重新进入。每次解释一项，默认正常中文语速，等待本人完成；不会按朗读时长跳步。

## 底部拨轮

除 API 密钥步骤外，配置操作集中在屏幕下方。左右滑动切换，咔哒声表示经过一档，停稳后朗读当前项；单击重听，双击执行。选择接口或模型时，双击进入选项拨轮，再滑动、双击确认；取消或系统返回键保留此前的选择。输入框仍可直接使用，也可以选“编辑”或“粘贴”操作。完整说明见 [拨轮使用说明](android-dial.md)。

进入设置页、需要拨轮的引导步骤、选项子菜单或返回主拨轮时，会朗读操作区位置、滑动选择、停下听取和双击确认的方法，并提示当前选项。移动拨轮时只读当前项，避免每一档重复整段说明；密钥页仍提示整页双击粘贴／保存。开启读屏时改为聚焦拨轮、双指滑动或无障碍调整操作的说明。

## 配合手机读屏

手机的 TalkBack／系统读屏负责告诉你焦点在哪：单指向右或向左滑动，依次听取控件名称；双击屏幕，执行当前选中的控件；双指滑动滚动页面。拨轮提供上一项、下一项和执行当前项的无障碍操作，地址和模型输入框有栏目标签；密钥引导页作为一个整体操作区，不显示输入框。拨轮获得焦点后可使用双指横滑或读屏的调整操作，厂商手势需实际设备确认。手势说明见 [Google TalkBack 帮助](https://support.google.com/accessibility/android/answer/6151827?hl=zh-Hans)。厂商读屏手势和开启快捷方式可能不同。

配置过程只需要拨轮、地址／模型输入框，以及密钥页的双击操作，不需要说话，也不会为配置启动麦克风。应用会逐项朗读说明，完成一项后再继续。系统权限弹窗和无障碍开关仍由本人通过手机读屏操作，应用不能代替系统授权。

## 完成配置

在拨轮选择“模型接口配置”并双击，进入服务商列表；左右滑动选择后双击确认，直接进入地址设置；选默认值也一样，不再需要第二次继续。需要返回、重听、暂停或稍后配置时，在拨轮中选择相应操作。

官方 API 地址预填。地址页拨轮默认停在“确认地址”，模型页默认停在“确认模型”；核对或编辑后双击，校验通过就进入下一项，失败留在当前页。模型名称可用读屏编辑，或显式粘贴服务商提供的名称。进入地址／模型页时先朗读当前实际值，再说明确认方法。地址的协议、域名和路径，以及模型中的点、短横线、下划线会明确读出。重听步骤和拨轮确认项也读出最新值。粘贴后立即播报，手动输入停顿约 1.2 秒后播报修改结果；重听或修改结束后拨轮停在对应确认项，听清后双击。空值提示尚未填写，格式错误提示检查；含账号或查询参数的不合法地址不回显到语音。

API 密钥页没有输入框和拨轮：先在其他应用复制密钥，返回后双击页面任意位置粘贴。应用只在这次明确操作时读取剪贴板，提示“已粘贴”，随后再双击才加密保存并进入测试步骤。单击和滚动都不粘贴或保存；粘贴不会自动调用模型 API。

需要更换密钥时，按系统返回键清除未保存的内容，留在当前页重新粘贴；尚未粘贴时返回键进入上一步。读屏模式下，整个密钥页作为一个可激活控件，聚焦后双击即可执行当前步骤。密钥不读出、不显示原文、不放入界面恢复数据；不提供密钥查询入口。中转服务的可选口令仍通过拨轮粘贴，未设置口令时可选择不使用口令继续。

小图测试需在拨轮选择“保存并测试识图连接”并双击才发送请求，可能产生一次 API 费用；失败停在当前项。测试成功不等于授权上传屏幕，需听取说明后明确双击“我了解并同意，继续”。

屏幕读取服务检测到连接后才继续。一加 ColorOS 可在系统无障碍的通用／已下载应用中查找“听见世界助手”，无需关闭手机自带读屏。若系统提示受限设置，按系统提示到应用信息处理。

日常语音待命、暂停讲解、图片自动描述、电池设置均可跳过。选择日常语音待命后，在结束引导时启动；配置过程本身不收音。离开引导停止引导朗读，未完成的测试取消；返回按已完成进度继续，未保存密钥需重新输入。退出引导时恢复先前已开启或刚明确选择的日常语音待命。

## 悬浮窗不再是必需入口

默认没有悬浮窗，屏幕读取和已开启的语音待命照常运行。在其他应用可说“小助手，描述屏幕”“小助手，读文字”“小助手，停止”。

需要跨应用备用入口时，在主界面拨轮选择“显示底部备用拨轮”，或说“小助手，显示悬浮窗”。它固定在其他应用的底部，同样通过滑动和双击操作；默认隐藏。进入听见世界时临时收起，避免与页面拨轮重叠。选择“隐藏悬浮窗，保留语音”或说“小助手，隐藏悬浮窗”可隐藏，不关闭服务，也不会在截图完成后重新弹出。
