# Android 逐项语音配置引导（1.4.0）

连接、屏幕上传同意或无障碍服务尚未就绪，以及上次引导未完成时，启动应用自动打开引导。已配置并授权的旧版本用户不会被强制从第一项重来。主界面的“逐项语音配置引导”可以手动进入。

## 配合操作节奏

- 一屏只显示当前配置项及其解释。默认调用系统中文 TTS，以 1.0 倍语速朗读，慢于默认 1.35 倍的屏幕描述；不会读完一段就自动跳步，也不会在输入过程中催促。
- 接口类型、地址、模型和密钥均需点击“完成本项，继续”。官方地址和模型预填，但仍让用户确认。密钥不在引导语句中，不在 Android 界面恢复数据中；确认后使用现有 Keystore 加密存储。
- 识图测试需用户点击才发起请求。测试失败留在本项并说明错误；成功只进入下一项，不自动同意屏幕上传。修改地址、接口、模型或密钥会使此前测试结果失效。
- 在独立一步说明屏幕上传用途，点击“我了解并同意”才授权。之后引导开启本应用的无障碍服务；从系统设置返回或检测到服务连接后继续，未授权不跳过。
- 麦克风语音待命、暂停讲解、图片自动描述和电池优化逐项解释，可选择暂不开启／暂不调整。权限弹窗须本人操作。语音服务开始运行不等于模型已经解压完成，返回主界面查看待命状态。

## 重听、暂停和继续

每一项都有“重听当前步骤”和“暂停语音引导”。暂停状态会保留，重听只朗读当前项，不改变配置。选择“稍后配置”可返回主界面，不会立即反复弹回引导；再次进入或重新启动时按已完成状态继续。

尚未确认的文本不会当作已完成；未保存的密钥在界面重建后需要重新输入。系统设置或权限被撤销后，会根据实际状态回到尚未完成的必要步骤。引导中离开页面会停止语音；未完成的连接测试被取消，返回后可手动重试，避免后台响应悄悄跳步。

## 与读屏、语音命令配合

检测到启用的语音无障碍服务时，提示交给系统无障碍朗读，不同时启动应用 TTS，速度由读屏器设置决定。应用自己的引导使用正常语速。进入输入框或系统页面会停止应用引导朗读。

引导前台期间不处理麦克风唤醒指令，避免引导中的词句被当成命令；引导页面也不作为待描述的其他应用页面。缺少中文 TTS 或声音通道不可用时保留文字提示，提供“中文语音设置”入口。不同厂商系统的 TTS、读屏和声音焦点效果仍需要真机验证。

本功能不代替系统授权，也不会自动点击系统设置开关。识图测试仍可能产生一次模型费用；引导本身不需要调用模型或上传屏幕。
