# Android 无视觉配置与操作（1.6.0）

配置未完成时，启动应用自动进入逐项引导。已完成用户可通过主界面的“逐项语音配置引导”重新进入。每次解释一项，默认正常中文语速，等待本人完成；不会按朗读时长跳步。

## 底部拨轮

所有应用内操作都集中在屏幕下方。左右滑动切换，咔哒声表示经过一档，停稳后朗读当前项；单击重听，双击执行。选择接口或模型时，双击进入选项拨轮，再滑动、双击确认；取消或系统返回键保留此前的选择。输入框仍可直接使用，也可以选“编辑”或“粘贴”操作。完整说明见 [拨轮使用说明](android-dial.md)。

## 配合手机读屏

手机的 TalkBack／系统读屏负责告诉你焦点在哪：单指向右或向左滑动，依次听取控件名称；双击屏幕，执行当前选中的控件；双指滑动滚动页面。拨轮提供上一项、下一项和执行当前项的无障碍操作，输入框有栏目标签，密钥使用密码输入框。拨轮获得焦点后可使用双指横滑或读屏的调整操作，厂商手势需实际设备确认。手势说明见 [Google TalkBack 帮助](https://support.google.com/accessibility/android/answer/6151827?hl=zh-Hans)。厂商读屏手势和开启快捷方式可能不同。

初次使用时，在拨轮找到“开启配置语音操作”并双击，允许麦克风。未启用读屏时，在引导页面按音量加键也可请求语音权限。**系统权限弹窗和无障碍开关仍需本人通过手机读屏操作**；应用不能代替系统授权。已开启读屏时不接管音量键。配置语音只需麦克风，不必先配置模型 API 或开启本应用的屏幕读取服务。

本地语音初次解压可能需要一到几分钟。应用自己的朗读结束后，再说“小助手”加具体命令。启用系统读屏时，提示交给读屏，应用不叠加 TTS；在拨轮选择“语音说一项”并双击，听提示音后八秒内说一条完整命令。每条确认指令也需重新打开输入窗口，避免自动把读屏内容当作同意。语音识别依赖发音和环境，识别失败可通过读屏控件继续。

## 配置命令

所有命令前加“小助手”，一次一句：

| 当前操作 | 说法 |
| --- | --- |
| 选择服务商 | 选择第一项（Gemini）、第二项（DeepSeek）、第三项（OpenAI）、第四项（自定义兼容接口）、第五项（中转服务） |
| 完成本项 | 下一步 |
| 返回或重听 | 上一步、再说一遍、帮助 |
| 输入密钥 | 先从服务商复制，再说“粘贴密钥”，确认后说“下一步” |
| 请求测试 | 测试连接；听复述后再说“确认操作”或“取消操作” |
| 允许屏幕上传 | 同意上传；听复述后再说“确认操作” |
| 可选功能 | 开启本项（另行确认），或跳过 |
| 系统设置 | 打开设置；随后使用手机读屏操作系统页面 |
| 暂停或退出 | 暂停朗读、稍后配置 |

官方 API 地址预填。模型名称可用读屏编辑，或显式粘贴服务商提供的名称。密钥不做语音听写，不读出内容、不放入界面恢复数据，确认后用 Android Keystore 加密保存；剪贴板仅在明确点击或说“粘贴”时读取。

小图测试需点击或通过两段语音确认才发送请求，可能产生一次 API 费用；失败停在当前项。测试成功不等于授权上传屏幕，“下一步”不能代替明确的屏幕上传同意。语音确认在切换步骤、离开界面、其他命令或超过九十秒后失效。

屏幕读取服务检测到连接后才继续。一加 ColorOS 可在系统无障碍的通用／已下载应用中查找“听见世界助手”，无需关闭手机自带读屏。若系统提示受限设置，按系统提示到应用信息处理。

日常语音待命、暂停讲解、图片自动描述、电池设置均可跳过。选择日常语音待命后，在结束引导时启动；它与配置期间的语音操作分开。离开引导停止配置录音和朗读，未完成的测试取消；返回按已完成进度继续，未保存密钥需重新输入。退出引导时恢复先前已开启或刚明确选择的日常语音待命。

## 悬浮窗不再是必需入口

默认没有悬浮窗，屏幕读取和已开启的语音待命照常运行。在其他应用可说“小助手，描述屏幕”“小助手，读文字”“小助手，停止”。

需要跨应用备用入口时，在主界面拨轮选择“显示底部备用拨轮”，或说“小助手，显示悬浮窗”。它固定在其他应用的底部，同样通过滑动和双击操作；默认隐藏。进入听见世界时临时收起，避免与页面拨轮重叠。选择“隐藏悬浮窗，保留语音”或说“小助手，隐藏悬浮窗”可隐藏，不关闭服务，也不会在截图完成后重新弹出。
