# 媒体导入原型

备用的 Expo / React Native / Web 客户端，供主动选择照片、拍照或导入视频后描述。跨 App 语音使用方式见 [屏幕助手](screen-assistant.md)。

## 启动

先按 [服务端说明](../server/README.md) 安装依赖、配置并启动 AI 服务，再在项目根目录运行：

```powershell
npm start        # 手机预览
npm run web      # 浏览器预览，端口 8081
```

手机需使用与项目 Expo SDK 兼容的 Expo Go 或开发构建；iOS 本地构建需要 macOS 和 Xcode。

在应用“连接设置”填写服务地址及访问令牌。真机使用电脑局域网地址或 HTTPS 服务；手机的 `localhost` 不指向电脑。Web 来源需加入服务端 `CORS_ORIGINS`，HTTPS 网页应连接 HTTPS API。

仅体验界面时，可使用“体验示例描述”，无需 AI 服务。示例是固定数据，不上传媒体、不调用模型。

## 使用

1. 选择照片、拍照或导入 **不超过 120 秒**的视频。
2. 选择简洁描述、详细描述或读取文字，查看结果。
3. 对当前媒体继续提问，或使用朗读、停止控件。
4. 清空时停止朗读并释放本次会话数据。

检测到 TalkBack / VoiceOver 开启时，默认关闭自动朗读；仍可主动朗读结果。

## 范围与数据

- 视频最多抽取 **12 帧**，不上传完整视频、不分析音轨；时间线只代表采样画面。
- 图片和视频帧先在端上缩放、压缩，再发往共用 AI 服务；每次追问都会重新发送当前帧。
- 应用不建立媒体或描述历史；清空时尝试删除处理缓存，系统选择器的临时文件由系统管理。
- AI 可能遗漏短暂动作、看不清文字或判断错误；应区分可见事实与不确定内容。
- 该入口的 Android / iPhone 真机流程尚待验收；原生 Android 屏幕助手的真实 AI 验证不等于此入口已通过。

构建、代码结构和自动检查见 [开发说明](development.md)；人工检查见 [验收表](acceptance.md)。
