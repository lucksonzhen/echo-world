# 版本更新记录

以下按发布版本记录历史行为；旧版本中提到的配置语音、悬浮按钮等可能已被后续版本替换。当前操作以 [README](../README.md) 为准，验证范围见 [验收记录](acceptance.md)。

## Android 1.6.11 自动图片与 Live 标签兼容

自动图片识别兼容“第几张图片”“1/9”等占位标签；对明确标注 Live／实况照片的绘图控件，自动描述当前一帧，同一区域在滚动或页面切换前只尝试一次。仍依赖应用暴露可定位的大图控件，不保证所有小红书页面可自动识别；手动“描述屏幕”不依赖图片控件，“看看视频”可观察动态过程。

## Android 1.6.10 字段兼容与明确诊断

DeepSeek 的细节、识别文字和不确定性说明支持单段文字及只含 text／description 的文字对象，忽略空条目；屏幕文字行数较多时无损合并相邻条目，保留内容和顺序。仍无法处理时，语音直接说明具体字段、类型或长度问题，再报 R04；不回显私人内容，也不自动重试。

## Android 1.6.9 屏幕描述 R02 兼容

DeepSeek 静态画面的简短／详细描述兼容完整普通中文回复，保留模型原文而不必强制转换为 JSON；同时兼容一层额外 JSON 字符串、单对象数组和紧凑代码块。损坏 JSON、截断、带推理标签的内容及多对象回复仍拒绝；视频、读字和提问继续使用结构化校验。不自动重试或增加调用。

## Android 1.6.8 DeepSeek 返回兼容

修正 DeepSeek 返回有效概要、但辅助字段省略或为空时被整体拒绝的问题。空回复、非 JSON、缺少概要、字段错误和输出截断分别提示，不再将返回校验失败一律归因于模型不支持图片。不自动重试或增加 API 请求；概要和有效内容的类型、长度、视频时间戳仍校验。

## Android 1.6.7 听清当前值再确认

地址和模型确认页会先朗读实际值，点、斜杠、短横线、下划线明确读出。进入页面、重听步骤、拨轮停在确认项时都使用输入框的最新值；粘贴后立即播报，手动输入停顿后播报修改结果。重听或修改结束后拨轮停回确认项，双击进入下一项。密钥依旧只播报状态，不读出内容。

## Android 1.6.6 确认后直接下一项

配置引导选择服务商后，双击确认即进入地址设置，不再另设“完成本项，继续”。确认默认选项也会前进；浏览或取消不会提交。地址和模型分别使用一次“确认地址”“确认模型”，校验通过后进入下一项。密钥仍保持粘贴后再次双击保存，测试和屏幕上传同意各自明确确认。

## Android 1.6.5 密钥双击粘贴

- API 密钥步骤使用独立整页操作：先复制密钥，双击屏幕粘贴；听到提示后，再双击保存并继续。无输入框和拨轮，不提供密钥查询入口。
- 粘贴成功只提示状态，不读出密钥，不自动保存或请求 API。空剪贴板会提示重试；系统返回键可清除未保存的密钥，重新粘贴。
- 其他配置步骤继续使用拨轮；手机读屏可聚焦整个密钥页面，再双击激活当前步骤。

进入设置页、需要拨轮的引导步骤、选项子菜单或返回主拨轮时，会朗读操作区位置、滑动选择、停下听取和双击确认的方法，并提示当前选项。移动拨轮时只读当前项，避免每一档重复整段说明；密钥页仍提示整页双击粘贴／保存。开启读屏时改为聚焦拨轮、双指滑动或无障碍调整操作的说明。

## Android 1.6.4 简化配置

- 完全移除配置语音指令、短时收音和音量键启动；升级时清理旧的配置语音开启状态。
- 设置统一使用底部拨轮，保留逐项朗读、停稳读选项、重听和暂停，不要求说话或为配置开启麦克风。
- 日常语音待命保留：明确开启后，可在其他应用说“小助手，描述屏幕”。

## Android 1.6.3 历史更新

- 曾增加配置语音的短时输入和错误反馈；该功能已在 1.6.4 移除。

## Android 1.6.2 入口命名

- 模型服务的拨轮入口固定显示“模型接口配置”；具体服务商显示在当前值区域，双击入口后再选择。

## Android 1.6.1 界面调整

- 配置页改为步骤进度、简短提示和独立当前值卡片，详细说明仍可完整朗读与重听。
- 底部拨轮采用浅色背景、细弧线和清晰选中项，统一输入框、字号、留白与页面配色。保留咔哒声、停稳朗读和双击确认。

## Android 1.6.0 更新

- 应用内按钮、下拉菜单、模型列表和上传授权选择统一为屏幕底部拨轮；上方内容滚动时位置不变，键盘出现时拨轮移到键盘上方。
- 左右滑动切换选项，每过一档播放短促咔哒声并提供轻触觉反馈；停稳后读出序号和完整名称。单击重听，双击执行，滑动不会保存或授权。
- 选择列表带取消返回；兼容读屏的上一项、下一项和执行操作。输入框保留，可在拨轮选择编辑或显式粘贴，密钥不读出。
- 可选的跨应用悬浮控件也改为底部拨轮，默认隐藏，进入本应用后自动收起以避免两个拨轮重叠。日常语音指令在应用内配置时暂停，回到其他应用恢复。
- 详见 [拨轮使用说明](android-dial.md)。Android 系统权限弹窗和输入法属于系统界面，不会被替换。

## Android 1.5.0 更新

- 悬浮窗默认隐藏；语音与屏幕服务独立运行。按需显示的备用按钮可拖动、记住位置，也支持读屏操作菜单移动和隐藏。
- 曾增加本地语音配置命令，1.6.4 已移除，改用拨轮完成配置。
- 与手机读屏配合：左右滑动听取控件、双击执行。
- 修正把应用自身无障碍服务误当成系统读屏的问题。初次麦克风授权、系统开关仍由用户通过系统读屏操作，详见 [无视觉配置说明](android-setup-guide.md)。

## Android 1.4.0 更新

- 新增逐项语音配置：一次只显示和讲解当前项，默认 1.0 倍语速；确认、测试成功或检测到权限开启后才继续，不按朗读时长跳步。
- 支持重听、暂停、稍后配置与进度恢复；密钥不进入引导语音或界面恢复数据。系统读屏启用时通过系统无障碍朗读提示。
- 引导覆盖连接配置、识图测试、上传说明、无障碍服务，以及可跳过的语音待命、暂停讲解、图片自动描述和电池设置。
- 1.4.0 配置期间暂停处理唤醒指令（1.5.0 曾支持专用配置命令，1.6.4 已移除），离开引导页面停止引导朗读；完整说明见 [语音配置引导](android-setup-guide.md)。

## Android 1.3.0 更新

- 新增 DeepSeek 官方手机直连，预填支持图片的 `deepseek-flash`，支持屏幕描述、读字、图片与视频采样帧。
- 使用非思考模式及 JSON 输出，沿用加密保存、结果校验和生成小图测试。无需电脑或同一局域网。
- 依据 [DeepSeek 官方图像文档](https://api-docs.deepseek.com/guides/vision/) 实现；真实密钥调用与一加真机仍需用户验证。

## Android 1.2.1 更新

- 拆分此前合并的 HTTP 400 / 404 / 422 提示，显示状态码，安全识别常见密钥、地区和账户条件错误。
- 从官方 API 获取当前密钥返回的 Gemini 候选模型，不上传截图或调用生成接口；选择后仍需小图测试。
- 连接结果同时显示在测试按钮下方，避免必须回到页面顶部查错。

## Android 1.2.0 更新

- 手机直接调用模型 API，默认 Gemini，支持 OpenAI 与可自填基础地址的兼容接口；保留可选中转模式。
- 本机加密保存密钥，切换接口时清空输入框；不跟随重定向，不回显上游错误正文，不自动重试计费请求。
- 用生成的小图验证真实请求格式；补充无障碍服务定位与受限设置提示。
- 个人手机试用构建关闭调试和 HTTP，沿用本机测试签名便于覆盖安装；不是应用商店正式签名。

## 1.1.0 更新

- **最近描述重听**：说“小助手，再说一遍”或使用悬浮按钮，直接重听最近一次成功的描述，不重新截图或上传；失败与取消不会覆盖它。文字仅暂存在内存，锁屏、撤销上传同意或关闭服务后清除。
- **权限总览**：首页集中展示无障碍服务、麦克风、通知使用权、待命通知和电池优化状态，提供对应设置入口，返回后自动刷新。
- **统一品牌**：Android、iOS、Web 和构建项目统一为听见世界 / EchoWorld；保留现有安装标识和设置存储键，支持已有用户继续升级。
