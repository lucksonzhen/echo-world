# 听见世界 · EchoWorld

帮助视障用户理解其他 App 中的图片、文字和视频画面，并用中文读出来。日常使用可直接说“小助手，描述屏幕”，无需寻找悬浮按钮、下载图片或把手机与电脑接到同一 Wi-Fi。

项目仓库：[lucksonzhen/echo-world](https://github.com/lucksonzhen/echo-world)，原名 blind-assistant。当前保留版本为 **Android 1.6.11 试用版**；本文按该版本说明。开发计划不代表现有功能。

**许可：仅限非商业用途，禁止商业使用。** 项目原创内容采用 [EchoWorld 非商业使用许可证](LICENSE)，第三方组件保留原许可。

## 下载与准备

- [下载 Android 1.6.11 APK](https://github.com/lucksonzhen/echo-world/releases/download/v1.6.11-preview.1/echo-world-1.6.11-android-dial.apk) · [版本归档与校验文件](https://github.com/lucksonzhen/echo-world/releases/tag/v1.6.11-preview.1)
- 需要 Android 11 或更高版本。当前 APK 约 81.2 MiB，使用个人测试签名，可覆盖此前相同签名的试用版。建议直接覆盖安装，避免卸载后重新配置。
- 仓库为私有时，下载需要登录有访问权限的 GitHub 账号。
- 准备所选模型服务的个人 API Key，先复制到手机剪贴板。密钥在手机配置，不要发到仓库、反馈或聊天中。
- 手机需要能访问所选 API，并具备可用的中文朗读声音。模型调用可能产生服务商费用。

**当前不是完全离线的视觉助手。** 唤醒词和语音指令在手机本地识别；图片理解仍需把画面发送到所选模型 API。当前试用 APK 内置 Vosk 中文小语音模型，它不负责看图。[本地视觉模型推理](docs/roadmap.md#本地视觉模型推理)是后续开发事项。

## 第一次打开：跟着语音逐项配置

未设置好时，应用自动进入逐项引导；以后可在主设置页找到“逐项设置引导”。每次只处理当前一项，完成或确认后才进入下一项，不会因为语音读完就跳步。配置过程不需要说话，也不会启用配置收音。

### 先掌握两种操作

**普通配置页用底部拨轮。** 手指在屏幕底部向左滑选下一项，向右滑选上一项。咔哒声表示经过一档；停下听选项，单击重听，双击执行。仅滑动不会保存、上传或调用 API。进入新页面或菜单时，会先说明操作方法。可在拨轮找到重听、返回、暂停引导或稍后配置等操作。

**API 密钥引导页用整页双击。** 该页没有拨轮，先双击粘贴，听到成功提示后，再双击保存。

如果已开启手机读屏，请先用读屏导航聚焦拨轮，再使用双指横滑或读屏提供的上一项／下一项操作，双击执行。普通单指左右滑通常用于移动读屏焦点；具体手势以手机读屏为准。密钥页是一个整体操作区，聚焦后双击即可。系统权限弹窗和输入法仍使用系统读屏操作。详见 [拨轮与读屏操作](docs/android-dial.md)。

### 按顺序完成设置

1. **选择模型服务。** 在“模型接口配置”进入服务商列表，听到所选服务后双击确认，直接进入地址设置。
2. **确认地址和模型。** 官方地址已经预填。应用会读出实际地址、模型名称及其中的标点；听清后双击“确认地址”或“确认模型”继续。需要修改时可编辑或粘贴，修改后会重新读出当前值。不要在基础地址后自行添加请求路径。
3. **粘贴密钥。** 在其他应用复制 Key，回到密钥引导页。第一次双击粘贴，听到成功后第二次双击保存并进入下一项。不会读出密钥原文。剪贴板为空时会提示重试；粘贴错了可按系统返回键清除未保存的内容，再重新粘贴。没有密钥查询入口。
4. **测试连接。** 双击“保存并测试识图连接”。只发送应用生成的小图，不读取手机屏幕，但可能产生一次 API 费用。失败时停留在本步骤；听取完整错误提示再处理。
5. **确认屏幕上传说明。** 测试成功后，听取说明并明确确认是否允许上传屏幕。小图测试成功不等于已授权上传屏幕。
6. **开启屏幕读取服务。** 进入系统无障碍设置，找到“听见世界助手”并开启，然后返回应用。手机自带的读屏可以继续保留；它负责操作界面，听见世界负责按要求截图并解释画面。
7. **按需开启日常语音待命。** 允许麦克风后，完成引导并回到其他 App 使用口令。暂停讲解、图片自动描述、电池设置均可跳过，以后再开启。

官方接口在 **1.6.11 中的预填值**如下；预填模型名称不代表你的账号一定可调用，最终以小图测试和实际服务权限为准。

| 接口类型 | API 基础地址 | 应用预填模型 |
| --- | --- | --- |
| Gemini 官方 API | `https://generativelanguage.googleapis.com/v1beta` | `gemini-3.5-flash` |
| DeepSeek 官方 API | `https://api.deepseek.com` | `deepseek-flash` |
| OpenAI 官方 API | `https://api.openai.com/v1` | `gpt-4.1-mini` |
| 自定义 OpenAI 兼容接口 | 填写服务商提供的 HTTPS 基础地址 | 填写服务商提供的视觉模型名称 |

主设置页提供“获取 Gemini 模型列表”；返回的候选仍需进行识图测试。自定义地址不要带 `/chat/completions` 或 `/responses`。手机直连用户无需填写电脑上的“描述服务”地址；“原有中转服务”仅用于已有服务端的用户。更多设置说明见 [手机直连 API](docs/android-direct-api.md)。

### 权限分别用于什么

| 权限或设置 | 用途 | 什么时候需要 |
| --- | --- | --- |
| “听见世界助手”无障碍服务 | 截图；自动图片模式还会读取前台控件类型、标签和位置来定位图片 | 屏幕描述需要 |
| 麦克风 | 在本地识别“小助手”和日常命令 | 开启语音待命时 |
| 通知使用权 | 获取播放器播放／暂停状态 | 可选的暂停讲解 |
| 待命通知 | 展示语音服务运行状态 | 按系统提示处理 |
| 电池优化／后台活动设置 | 尝试减少服务被系统关闭 | 待命经常中断时再调整 |

一加等手机的入口名称会随系统版本不同而变化，可在系统无障碍中查找已下载应用或第三方服务里的“听见世界助手”。若出现“受限设置”，按系统提示检查本应用的信息页；不需要关闭手机自带读屏。系统授权不能由应用代替完成。完整流程见 [无视觉配置说明](docs/android-setup-guide.md)。

## 配置好以后怎么用

回到想了解内容的 App，保持手机解锁并停留在目标画面。可以完整说一句命令；也可以先说“小助手”，听到提示音后，在八秒内说出要求。

| 你可以说 | 会发生什么 |
| --- | --- |
| 小助手，描述屏幕 | 截取并详细描述当前屏幕 |
| 小助手，读文字 | 识别并朗读当前可见文字 |
| 小助手，左边那张图片有什么？ | 针对当前画面回答问题 |
| 小助手，看看视频 | 约八秒采样六帧，描述观察到的变化；不分析原声，观察期间请继续播放 |
| 小助手，再说一遍 | 重听最近一次成功描述，不重新截图或调用 API |
| 小助手，快一点／慢一点／正常语速 | 调整日常描述的语速 |
| 小助手，开启／关闭图片自动描述 | 控制浏览时的大图自动简述 |
| 小助手，开启／关闭暂停讲解 | 控制播放器暂停后的当前帧讲解 |
| 小助手，停止监控屏幕 | 关闭两种自动模式并取消当前任务，保留语音待命 |
| 小助手，停止 | 停止任务和朗读，也关闭两种自动模式，保留语音待命 |
| 小助手，关闭语音监听 | 关闭麦克风待命 |

朗读过程中可直接说停止、重听、调速及关闭自动模式的口令。若要提出新描述或问题，先说“小助手，停止”，再说新的要求；需要自动模式时之后重新开启。

默认隐藏跨应用悬浮拨轮，不影响已开启的语音服务。需要备用入口可在主设置页选择“显示底部备用拨轮”，或说“小助手，显示悬浮窗”；“小助手，隐藏悬浮窗”可将它收起。应用内配置期间暂停日常唤醒处理，回到其他 App 后恢复。手机重启或系统结束服务后，可能需要重新打开应用开启语音待命。

## 自动图片、Live 图和暂停讲解

图片自动描述默认关闭。开启后，页面稳定约 1.2 秒才检查控件，持续变化的页面最多等约 3 秒；一般只寻找没有实际文字说明、面积至少约占屏幕十分之一的大图。成功描述后至少间隔四秒，同图按指纹去重。滚动、切换应用或锁屏会取消当前自动描述。

1.6.11 兼容“第几张图片”“1/9”等占位标签，也识别明确标注 Live／实况照片的部分绘图控件。**Live 自动描述的是当前一帧**；同一区域在滚动或页面切换前最多自动尝试一次，包括失败，避免动画持续变化引起重复上传。想了解动态过程可手动说“看看视频”。

小红书等应用的不同页面可能暴露不同控件，当前不能保证每张图都自动触发。已有真实文字说明、图片太小、没有可定位图片控件、同图去重等都可能跳过。自动截图或 API 失败目前只更新状态，不主动出声；若没反应，手动说“描述屏幕”可以绕过图片定位，并听到具体错误。

暂停讲解需要通知使用权和播放器提供的播放状态；应用检测到从播放变为暂停后描述当前帧，继续播放会取消。部分播放器不提供状态，因此不能保证所有 App 都触发。两种自动模式均不会替你滚动或操作目标 App。

## 常见问题

| 情况 | 先这样处理 |
| --- | --- |
| 有手机自带读屏，还要开另一个服务吗？ | 保留读屏，同时开启“听见世界助手”；两者职责不同。 |
| 说话没反应 | 确认已开启日常语音待命、麦克风可用、手机解锁，且已离开听见世界配置页；检查待命通知和后台限制。 |
| 没有朗读声音 | 检查媒体音量、读屏／中文 TTS 状态，以及声音是否输出到耳机；系统页面依赖手机读屏。 |
| 测试成功，但屏幕描述失败 | 小图测试不保证所有画面请求都成功。记录完整错误、模型名、版本和“仅屏幕失败”的情况。 |
| 报 R04 | 听取 R04 前面的具体字段和原因；它是返回字段校验失败，不能单凭编号认定地址错误。 |
| 自动图片没反应或 Live 图漏掉 | 先手动“描述屏幕”。手动成功通常可将排查重点放在自动触发条件；手动失败则先处理播报的错误。 |
| 无障碍开关受限制／找不到 | 从应用“开启屏幕读取服务”进入系统设置，找“听见世界助手”；受限时按系统提示处理应用信息页。 |
| 受保护页面无法截图 | 当前无法描述该页面；锁屏也不采集。 |
| 想换 Key 或停止上传 | 可重新进入逐项引导；主设置页可撤销屏幕上传同意或“清除本机密钥”。后者会停止识别与语音待命。 |

反馈请包含：应用版本、手机型号和系统版本、接口类型和模型名、完整诊断提示、手动／自动及小图测试各自结果。**不需要 API Key、私人截图或模型原始回复。**

## 数据如何处理

API Key 使用 Android Keystore 加密保存，不内置公共密钥。手机直连时，压缩画面发送给所选服务商；自定义接口运营方也会收到请求及用于认证的密钥。当前试用包只允许 HTTPS，不自动重试计费请求。

语音识别在本机执行，应用不上传或保存麦克风录音。截图和用于定位图片的控件信息只在内存处理，不保存到相册；控件信息不上传，自动图片上传裁剪后的图片区域。最近一次描述暂存在内存，供“再说一遍”使用，锁屏、撤销同意或关闭屏幕服务后清除。第三方模型服务对收到数据的处理仍取决于该服务的政策。
