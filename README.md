# 听见世界 · EchoWorld

An AI screen companion that turns visual content into spoken understanding.

项目仓库：[lucksonzhen/echo-world](https://github.com/lucksonzhen/echo-world)。原名为听见屏幕 / 听见画面（blind-assistant）。

帮助盲人理解其他 App 中的图片、文字和视频画面，无需下载或导入媒体。

- **Android 11+**：说“小助手，描述屏幕”；可开启暂停讲解，视频暂停后自动描述当前帧；也可开启图片自动描述，浏览时遇到没有文字说明的大图自动简述；说“停止监控屏幕”关闭全部自动模式。
- **iPhone**：通过 Siri 快捷指令“截屏 → 描述 → 朗读”。目前提供源码，需在 Mac 上构建。
- **AI**：Android 支持手机直连 Gemini、DeepSeek、OpenAI 及 OpenAI 兼容接口；语音唤醒在手机本地完成，画面直接发送到所选模型 API。Web / iOS 仍使用描述服务。

## 快速开始

### Android 手机直连版（无需电脑）

1. 安装 [Releases](https://github.com/lucksonzhen/echo-world/releases) 中的 Android 1.6.5 手机直连试用包，可覆盖此前试用包。要求 Android 11+。设置未完成时自动进入逐项语音引导。
2. 默认选择 **Gemini 官方 API**，官方地址已填好；在手机输入自己的 Gemini API Key，可在底部拨轮找到“获取 Gemini 模型列表”，双击后选择候选模型。手机网络必须能访问 Gemini API。
3. 在底部拨轮选择“保存并测试识图连接”并双击：仅发送应用生成的几何图形，不截图，会产生一次 API 调用。测试成功后听取屏幕识别说明，再明确确认是否允许上传屏幕。
4. 开启“听见世界助手”无障碍服务；按需允许麦克风并开启语音待命。返回图片或视频 App，说“小助手，描述屏幕”。

API Key 用 Android Keystore 加密保存在手机；不会内置公共密钥，也不提供免费模型额度。截图仍会离开手机发送给所选 API，这不是离线视觉模型。可用“一键清除本机密钥”停止使用。详见 [手机直连配置](docs/android-direct-api.md)。

**使用 DeepSeek**：选择“DeepSeek 官方 API”，地址自动填入 `https://api.deepseek.com`，默认模型 `deepseek-flash`；输入 DeepSeek Key 后保存并测试。切换服务商需重新输入密钥并确认屏幕上传说明。

### Web / iOS 或原有中转模式

按 [服务端说明](server/README.md) 在电脑或服务器配置 `.env`，运行 `npm install` 和 `npm run server:local`。Android 可选“原有中转服务”，但手机直连试用构建只接受 HTTPS；仅 debug 构建允许开发用 HTTP。

常用命令：**描述屏幕、读文字、再说一遍、看看视频、开启／关闭暂停讲解、开启／关闭图片自动描述、停止监控屏幕、快一点／慢一点、停止**，前面加“小助手”。

### Android 1.6.5 密钥双击粘贴

- API 密钥步骤使用独立整页操作：先复制密钥，双击屏幕粘贴；听到提示后，再双击保存并继续。无输入框和拨轮，不提供密钥查询入口。
- 粘贴成功只提示状态，不读出密钥，不自动保存或请求 API。空剪贴板会提示重试；系统返回键可清除未保存的密钥，重新粘贴。
- 其他配置步骤继续使用拨轮；手机读屏可聚焦整个密钥页面，再双击激活当前步骤。

进入设置页、需要拨轮的引导步骤、选项子菜单或返回主拨轮时，会朗读操作区位置、滑动选择、停下听取和双击确认的方法，并提示当前选项。移动拨轮时只读当前项，避免每一档重复整段说明；密钥页仍提示整页双击粘贴／保存。开启读屏时改为聚焦拨轮、双指滑动或无障碍调整操作的说明。

### Android 1.6.4 简化配置

- 完全移除配置语音指令、短时收音和音量键启动；升级时清理旧的配置语音开启状态。
- 设置统一使用底部拨轮，保留逐项朗读、停稳读选项、重听和暂停，不要求说话或为配置开启麦克风。
- 日常语音待命保留：明确开启后，可在其他应用说“小助手，描述屏幕”。

### Android 1.6.3 历史更新

- 曾增加配置语音的短时输入和错误反馈；该功能已在 1.6.4 移除。

### Android 1.6.2 入口命名

- 模型服务的拨轮入口固定显示“模型接口配置”；具体服务商显示在当前值区域，双击入口后再选择。

### Android 1.6.1 界面调整

- 配置页改为步骤进度、简短提示和独立当前值卡片，详细说明仍可完整朗读与重听。
- 底部拨轮采用浅色背景、细弧线和清晰选中项，统一输入框、字号、留白与页面配色。保留咔哒声、停稳朗读和双击确认。

### Android 1.6.0 更新

- 应用内按钮、下拉菜单、模型列表和上传授权选择统一为屏幕底部拨轮；上方内容滚动时位置不变，键盘出现时拨轮移到键盘上方。
- 左右滑动切换选项，每过一档播放短促咔哒声并提供轻触觉反馈；停稳后读出序号和完整名称。单击重听，双击执行，滑动不会保存或授权。
- 选择列表带取消返回；兼容读屏的上一项、下一项和执行操作。输入框保留，可在拨轮选择编辑或显式粘贴，密钥不读出。
- 可选的跨应用悬浮控件也改为底部拨轮，默认隐藏，进入本应用后自动收起以避免两个拨轮重叠。日常语音指令在应用内配置时暂停，回到其他应用恢复。
- 详见 [拨轮使用说明](docs/android-dial.md)。Android 系统权限弹窗和输入法属于系统界面，不会被替换。

### Android 1.5.0 更新

- 悬浮窗默认隐藏；语音与屏幕服务独立运行。按需显示的备用按钮可拖动、记住位置，也支持读屏操作菜单移动和隐藏。
- 曾增加本地语音配置命令，1.6.4 已移除，改用拨轮完成配置。
- 与手机读屏配合：左右滑动听取控件、双击执行。
- 修正把应用自身无障碍服务误当成系统读屏的问题。初次麦克风授权、系统开关仍由用户通过系统读屏操作，详见 [无视觉配置说明](docs/android-setup-guide.md)。

### Android 1.4.0 更新

- 新增逐项语音配置：一次只显示和讲解当前项，默认 1.0 倍语速；确认、测试成功或检测到权限开启后才继续，不按朗读时长跳步。
- 支持重听、暂停、稍后配置与进度恢复；密钥不进入引导语音或界面恢复数据。系统读屏启用时通过系统无障碍朗读提示。
- 引导覆盖连接配置、识图测试、上传说明、无障碍服务，以及可跳过的语音待命、暂停讲解、图片自动描述和电池设置。
- 1.4.0 配置期间暂停处理唤醒指令（1.5.0 曾支持专用配置命令，1.6.4 已移除），离开引导页面停止引导朗读；完整说明见 [语音配置引导](docs/android-setup-guide.md)。

### Android 1.3.0 更新

- 新增 DeepSeek 官方手机直连，预填支持图片的 `deepseek-flash`，支持屏幕描述、读字、图片与视频采样帧。
- 使用非思考模式及 JSON 输出，沿用加密保存、结果校验和生成小图测试。无需电脑或同一局域网。
- 依据 [DeepSeek 官方图像文档](https://api-docs.deepseek.com/guides/vision/) 实现；真实密钥调用与一加真机仍需用户验证。

### Android 1.2.1 更新

- 拆分此前合并的 HTTP 400 / 404 / 422 提示，显示状态码，安全识别常见密钥、地区和账户条件错误。
- 从官方 API 获取当前密钥返回的 Gemini 候选模型，不上传截图或调用生成接口；选择后仍需小图测试。
- 连接结果同时显示在测试按钮下方，避免必须回到页面顶部查错。

### Android 1.2.0 更新

- 手机直接调用模型 API，默认 Gemini，支持 OpenAI 与可自填基础地址的兼容接口；保留可选中转模式。
- 本机加密保存密钥，切换接口时清空输入框；不跟随重定向，不回显上游错误正文，不自动重试计费请求。
- 用生成的小图验证真实请求格式；补充无障碍服务定位与受限设置提示。
- 个人手机试用构建关闭调试和 HTTP，沿用本机测试签名便于覆盖安装；不是应用商店正式签名。

### 1.1.0 更新

- **最近描述重听**：说“小助手，再说一遍”或使用悬浮按钮，直接重听最近一次成功的描述，不重新截图或上传；失败与取消不会覆盖它。文字仅暂存在内存，锁屏、撤销上传同意或关闭服务后清除。
- **权限总览**：首页集中展示无障碍服务、麦克风、通知使用权、待命通知和电池优化状态，提供对应设置入口，返回后自动刷新。
- **统一品牌**：Android、iOS、Web 和构建项目统一为听见世界 / EchoWorld；保留现有安装标识和设置存储键，支持已有用户继续升级。

## 当前状态

历史中转版本已在 Android 模拟器跑通 **暂停 → 截图 → Gemini 真实识别 → 中文朗读**。Android 1.2.0 手机直连通过协议替身、加密保存及界面检查；真实 Gemini Key、真人麦克风、真机和盲人用户体验仍待验收，详见[验证记录](docs/acceptance.md)。

暂停讲解只适用于提供播放状态的 App；截图受保护的页面无法识别。视频理解使用抽样画面，不分析原声。截图会发送给所配置的 AI 服务。Android 直连模式的密钥加密保存在手机；Web / iOS 和中转模式的模型密钥只保存在服务端。
